# 25. Debugowanie i utrzymanie

## Dla kogo i po co

Dla osób diagnozujących błędy w działających projektach i utrzymujących kod przez wiele wersji toolchainu oraz zależności.

## Wymagania wstępne

Cargo, testy, obsługa błędów, podstawy systemu operacyjnego i doświadczenie z większym projektem.

## Kolejność materiałów

1. Minimalna reprodukcja, logi i czytanie backtrace.
2. Debugger, symbole, core dump i analiza stanu procesu.
3. Izolowanie regresji, `cargo bisect-rustc` i aktualizacje zależności.
4. Dług techniczny, migracje API i procedury incydentowe.

## Po tym dziale

Potrafisz zawęzić problem, zebrać dowody i naprawić przyczynę bez maskowania objawu.

## Co dalej

Połącz debugowanie z testami zaawansowanymi i obserwowalnością. Utrzymuj małe reprodukcje jako testy regresji.
