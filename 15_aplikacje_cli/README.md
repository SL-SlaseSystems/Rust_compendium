# 15. Aplikacje CLI

## Dla kogo i po co

Dla osób budujących narzędzia terminalowe: od małego polecenia po dystrybuowany program z konfiguracją, logowaniem i stabilnym interfejsem.

## Wymagania wstępne

Obsługa błędów, pliki i procesy, Cargo, testy oraz podstawy architektury aplikacji.

## Kolejność materiałów

1. [Komendy, argumenty, kody wyjścia i konfiguracja](01_komendy_argumenty_i_konfiguracja.md) — publiczny kontrakt CLI i scalanie argumentów, środowiska oraz plików.
2. [Strumienie, sygnały, testy procesu i dystrybucja](02_strumienie_sygnaly_testy_i_dystrybucja.md) — potoki, anulowanie, testy end-to-end i artefakty dla targetu.

Każdy rozdział zawiera trzy ćwiczenia z pełnymi rozwiązaniami; najpierw wykonaj je samodzielnie, potem porównaj kontrakty i przypadki graniczne.

## Po tym dziale

Potrafisz zaprojektować przewidywalne CLI, rozdzielić warstwę terminala od domeny i przetestować zachowanie procesu.

## Co dalej

Połącz tę ścieżkę z serializacją, obserwowalnością i release engineeringiem. Pierwszym projektem przekrojowym może być narzędzie przetwarzające dane ze standardowego wejścia.
